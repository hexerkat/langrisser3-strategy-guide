# Sources & Acknowledgements

This guide is part of the **Langrisser III (Sega Saturn) English translation
project**. Every line of in-game text quoted here is pulled **live from the
translated scripts**, so the guide tracks the patch as it is refined.

## How facts were checked

The **Japanese game text is the single source of truth.** Scenario flow, dialogue
choices, and quoted lines are taken from the game's own scripts; names follow the
project's canonical glossary (the source guides below use the authors' romaji,
which served as *context only*, never as spelling).

Two community guides were used as cross-reference oracles. Facts taken from them
were checked against the Japanese game data wherever the game holds them
(dialogue, choices, item, class and unit names).

- **Budianto's Langrisser III FAQ/Walkthrough** (English, GameFAQs).
  Reference for scenario titles, victory/defeat conditions, NPC and enemy
  rosters, buried-item locations, battle tactics, the branching dialogue choices
  and their love-index effects, and the secret-scenario triggers.

- **The Japanese strategy data «LANGRISSER III SS の攻略データです»** (攻略データ).
  Reference for the character-creation quiz branches, the class lines and hidden
  class-up items, the heroine / love-index choice tables, the full item list
  (prices, where sold, where found), the per-map buried items, and the
  secret-scenario and ending routes.

Two Japanese web guides were used to cross-check turn triggers, victory and
defeat rules, hidden items and the best-ending route:

- **らいおさむのお屋敷** (Osamu Rai), the scenario walkthrough and hidden item
  list for the Saturn and PS2 versions
  ([strategy](https://osamurai.azimech.net/langrisser/03/strategy),
  [hidden items](https://osamurai.azimech.net/langrisser/03/hide_item)).
- **攻略 - ラングリッサー3**, the branching page
  ([scenario branches](https://langrisser3.xn--1-td6bm19b.com/lng3-bunki.html)).

Where the sources disagree (a few love-index effects, some turn numbers), the
guide follows the one that matches the game's own script, or the 攻略データ.

The [Langrisser wiki](https://www.langrisser.wiki/wiki/Langrisser_III) was a
secondary reference for series-canonical name spellings.

Thanks to both authors. Their work made this guide far easier to assemble and
verify.
